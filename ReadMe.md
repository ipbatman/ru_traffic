# RuTraffic — учёт входящего трафика на Windows

**RuTraffic** показывает, сколько данных скачивает каждое приложение и какая часть трафика приходит напрямую с российских серверов. Программа работает на Windows 11 x64 и учитывает трафик при раздельной маршрутизации (split tunneling). Проект родился на фоне слухов, что в будущем правительство РФ будет отдельно тарифицировать зарубежный трафик. Программа поможет оценить, сколько зарубежного трафика вы потребляете.

## Что показывает программа

- Общий объём скачанных данных и статистику по приложениям.
- IP источника, страну и маршрут соединения за текущий сеанс.
- Историю за 12 месяцев с выбором периода и экспортом в CSV.

| Категория | Какой трафик в неё входит |
| --- | --- |
| **RU** | Прямые соединения с IP, которые база относит к России. |
| **Остальной интернет** | Прямые соединения с зарубежными IP и весь трафик через VPN. |
| **Не определено** | Трафик, для которого программа не смогла определить маршрут или страну прямого соединения. |

Страну программа определяет по IP-адресу. Например, если сервер сайта `.ru` находится за пределами России, прямое соединение с ним попадёт в «Остальной интернет».

## Установка и запуск

1. Запустите `RUTraffic-Setup-…-x64.exe` и следуйте шагам установщика.
2. Откройте RuTraffic из меню «Пуск».
3. Подтвердите запрос прав администратора. Они нужны драйверу WinDivert для захвата трафика.

При сворачивании RuTraffic продолжает учёт в системном трее. Чтобы остановить учёт и закрыть программу, выберите **«Выход»** в меню значка. Автозапуск можно включить в настройках.

## Если вы используете VPN

Подключите VPN и откройте настройки RuTraffic. Проверьте, что виртуальный адаптер отмечен как **VPN**. Затем укажите IP-адрес и UDP-порт из параметра `Endpoint` вашей конфигурации. Это помогает исключить внешние зашифрованные пакеты и снизить риск двойного учёта. Ключи VPN вводить не нужно.

При раздельной маршрутизации на вкладке **«Источники»** можно проверить, какой трафик RuTraffic определил как **VPN**, а какой — как **«Напрямую»**.

## Данные и поддержка

RuTraffic хранит историю, настройки и журнал в `%LOCALAPPDATA%\RUTraffic`. Страну он определяет по локальной базе DB-IP Lite. Счётчики могут отличаться от данных провайдера.

Если захват не запускается, укажите версию программы и код ошибки в [GitHub Issues](https://github.com/ipbatman/ru_traffic/issues). При необходимости приложите строки с ошибкой из `activity.log`.
